# Susanne Pedersen – Personal Website

Live site: https://susannepedersen.no

## About the Project

This is my personal website, created and developed as an independent web development project. The purpose of the site is to promote my music and singing services, provide an easy way for potential clients to get in touch, and create a professional digital presence.

The website was designed and built from scratch by me, with focus on:
- user experience
- responsive design
- clean and modern UI
- accessibility and usability
- personal branding

The project was also a way for me to further develop my frontend and problem-solving skills through hands-on development and real-world deployment.

## Features

- Responsive design for desktop and mobile
- Contact and booking information
- Presentation of singing/music services
- Clean and user-friendly layout
- Live deployment on custom domain

## Purpose

The website was created both as:
1. A practical web development project
2. A real-world platform for marketing and communication

Building something with an actual purpose and real users helped me gain experience with both technical implementation and thinking from a user perspective.

## Technologies

Technologies/tools used in the project:
- HTML
- CSS
- JavaScript
- Responsive web design
- Git/GitHub
- Deployment and domain configuration

## What I Learned

Through this project I gained experience with:
- building and maintaining a live website
- frontend development and UI decisions
- debugging and iterative improvement
- deployment workflows
- structuring a project independently from idea to production

I also used AI tools such as ChatGPT during parts of the development workflow for brainstorming, troubleshooting, and improving implementation ideas.
